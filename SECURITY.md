# Security Policy

## Supported versions

Until Harnessmith reaches 1.0, security fixes are applied to the latest
released minor version. Users should upgrade to the newest release before
reporting an issue that may already be fixed.

## Reporting a vulnerability

Please use GitHub's private security advisory form for this repository:

<https://github.com/kevinglover/harnessmith/security/advisories/new>

Do not open a public issue for a suspected vulnerability. Include affected
versions, reproduction steps, impact, and any suggested mitigation. Please
allow maintainers a reasonable opportunity to investigate and coordinate a
fix before public disclosure.

Harnessmith processes files and emits executable skill packages. Reports about
path traversal, generated-file ownership, provenance bypasses, unsafe script
generation, or semantic-policy weakening are especially valuable.
