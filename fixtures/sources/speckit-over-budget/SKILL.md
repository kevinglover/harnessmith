# Feature planner

Preserve every mandatory requirement and explicitly identify unresolved decisions.

## Discovery

Inspect the repository structure, build system, tests, runtime boundaries, configuration,
and established conventions. Record evidence for architectural assumptions. Distinguish
facts observed in source from inferences. Do not silently broaden the requested feature.

## Design

Describe data flow, interfaces, failure behavior, compatibility constraints, migration,
security boundaries, observability, and rollback. Map each requirement to implementation
work and verification. Keep optional improvements separate from required scope.

## Delivery

Order work by dependency. Give every task a concrete outcome and likely file location.
Identify tasks that can safely run in parallel and those requiring a shared contract first.

## Verification

Cover unit, integration, compatibility, and regression checks. Include negative cases,
malformed input, unsafe paths, stale state, repeat execution, and deterministic output.
